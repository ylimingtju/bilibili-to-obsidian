# Vault rules / 知识库协作规则

Read this file and `方法论/学习目标.md` before editing this vault. Follow the owner's edits to these files. 在写入前读取本文件和学习目标，以当前库主人的规则为准。

- **Sources / 原始资料** — Create one timestamped transcript per video part in `raw/B站/`. Reuse an existing transcript. 每个分 P 保存一份字幕，保留 BV 号、分集、来源和时间戳。
- **Synthesis / 方法论** — Keep reusable methods separate from dated opinions and forecasts. Cite the source note and timestamps, distinguish the speaker's claims from the assistant's inference, and use the actual assistant's name. 将长期方法与当期判断分开，注明出处并署名推断。
- **Edits / 写入** — Reread targets before editing, preserve user-written passages and only append to notes with `reviewed: true`. Append a dated entry in `AI 工作日记/YYYY-MM-DD.md` for changes to methodology. 写前重读，保护手写内容，已审核的笔记只追加。方法论有修改时记当天工作日记。
- **Archives / 归档** — Put complete investment answers in `方法论/投资推演记录/YYYY-MM.md` for the month under discussion. Append follow-ups with their actual dates. 按研判针对的月份归档，保留原答。
- **Wiki** — The owner may separately run an Obsidian ingestion plugin on selected raw sources. Leave plugin-managed pages and `.obsidian/` settings to the owner. 方法论笔记直接使用；可选的 Wiki 摄入由库主人在 Obsidian 中执行。
